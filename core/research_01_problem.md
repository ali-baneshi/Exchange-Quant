# سند تحقیقاتی ۱: مسئله بی‌راه‌حل
## Intent Trilemma در بازارهای مالی

### ۱.۱ بیان مسئله

در بازارهای مالی، یک معامله‌گر بزرگ با سه نیاز متناقض روبروست:

```
نیاز ۱: شفافیت (Transparency)
  → برای کشف قیمت مناسب، باید نیت خود را نشان دهد
  → ولی این یعنی لو رفتن اطلاعات → front-running

نیاز ۲: حریم خصوصی (Privacy)
  → برای محافظت از نیت خود، باید اطلاعات را پنهان کند
  → ولی این یعنی عدم کشف قیمت → adverse selection

نیاز ۳: سرعت (Speed)
  → برای اجرای باکیفیت، باید سریع عمل کند
  → ولی سرعت با شفافیت و حریم خصوصی در تضاد است
```

**هیچ راه‌حل کلاسیکی هر سه نیاز را همزمان برآورده نمی‌کند.**

### ۱.۲ راه‌حل‌های موجود و شکست‌های آن‌ها

| راه‌حل | مشکل |
|--------|------|
| Iceberg Orders | با تحلیل الگو قابل تشخیص است |
| Dark Pools | نقدینگی محدود + اطلاعات به بیرون درز می‌کند |
| TWAP/VWAP | کاملاً قابل پیش‌بینی |
| ZKP-based | بسیار کند برای تطبیق بلادرنگ |
| TEE-based | نیاز به اعتماد به سخت‌افزار |
| Commit-Reveal | در بازه commit تا reveal قابل سوءاستفاده |

### ۱.۳ هسته مسئله

ریشه مسئله در این است که **نیت (intent) یک متغیر کلاسیک نیست که بتواند هم پنهان بماند و هم در کشف قیمت مشارکت کند.**

این دقیقاً مشابه پارادوکس اندازه‌گیری در مکانیک کوانتوم است:
- اندازه‌گیری حالت کوانتومی را فرومی‌ریزد
- مشاهده‌ی نیت معامله‌گر، آن نیت را تغییر می‌دهد

### ۱.۴ چرا احتمال کلاسیک نمی‌تواند

قانون احتمال کل (Law of Total Probability):

P(A) = P(A|B₁)P(B₁) + P(A|B₂)P(B₂) + ... + P(A|Bₙ)P(Bₙ)

این قانون فرض می‌کند که متغیرهای B₁, B₂, ..., Bₙ قابل مشاهده و مستقل از زمینه (context-independent) هستند. در بازار، متغیرهای پنهان زیادی وجود دارند که این قانون را نقض می‌کنند.
