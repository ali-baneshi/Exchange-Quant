## این پوشه چیست؟

درسنامه‌ها (نه فقط «مستندات فنی») برای کسی نوشته شده‌اند که می‌خواهند **Exchange-Q را بفهمند، بکار بگیرند، و انتقادی قضاوت کنند** — حتی اگر پیش‌زمینه کوانتوم یا مالی نداشته باشند.

هر نسخه درسنامه به **یک لحظه مشخص از سیستم** گره خورده است. وقتی کد، schema، یا runbook عوض شد، **نسخه جدید** با تاریخ جدید اضافه می‌شود؛ نسخه‌های قدیمی حذف نمی‌شوند تا بدانید هر درس برای کدام وضعیت نوشته شده.

## قواعد نسخه‌بندی (برای نویسنده و خواننده)

1. **هر درس** در ابتدا بلوک «مشخصات نسخه» دارد: تاریخ، commit، schema، فایل‌های کلیدی.
2. اگر تنظیمات عوض شد (مثلاً `MIN_SIGNIFICANCE_N` یا horizon پیش‌فرض)، **درس جدید** یا **بخش «تغییرات نسبت به نسخه قبل»** اضافه شود.
3. درس‌های قدیمی **آرشیو** می‌مانند — روی run جدید بدون چک snapshot تکیه نکنید.
4. ترتیب پیشنهادی: `00 → 01 → … → 08`؛ می‌توانید L01 را بپرید اگر پیش‌زمینه دارید.
